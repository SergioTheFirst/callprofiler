# Гипотезы (записаны до данных; каждая — с предсказанием и тем, что её опровергнет)

| H | Гипотеза | Предсказание (число) | Опровергает | Эксперимент |
|---|---|---|---|---|
| H1 | В боевой БД `bs_index` никогда не превышает 20 и 4 из 5 счётчиков формулы нулевые (D1) | `MAX(bs_index) ≤ 20`; `vagueness_count = blame_shift_count = emotional_spikes = broken_promises = 0` во всех строках `entity_metrics` | любая строка с ненулевым счётчиком | E-0a, script 01 |
| H2 | Разрешённые исходы есть у меньшинства контактов | доля контактов с ≥4 разрешёнными исходами (kept/late/broken, side=contact) < 0.25; медиана n разрешённых = 0 | доля ≥ 0.5 | E-0a, script 02 |
| H3 | det-разрешитель исходов точен умеренно | q_det ∈ [0.6, 0.8]; sens ≥ spec (regex ловит «сделал» лучше, чем «не смог») | q_det < 0.5 или > 0.9 | E-1 |
| H4 | Роли перепутаны редко среди обещаний, но UNKNOWN-доля заметна | перепутанных ролей < 5% adjudicated; средняя UNKNOWN-доля звонков с обещаниями 0.1–0.3 | перепутано ≥ 10% | E-1, E-0a script 03 |
