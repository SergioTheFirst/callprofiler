**Ключевые выводы в одну строку каждый:**
1. Текущий BS-index в проде = `20·min(contradictions/calls,1)`; 4 из 5 членов мертвы; заморозить, не чинить.
2. Единственный сигнал с внешним критерием — исходы обязательств (`promise_outcomes`) → конструкт CR
   («частота исполнения обязательств в диаде»), Beta-binomial с измеряемым шумом ярлыков.
3. CI 1–100 = масса posterior в окне ±0.1 вокруг медианы; проверяется reliability diagram; число
   включается только после ≥150 adjudicated исходов (✓/✗-петля).
4. Большинство контактов — «данных мало»; факты показываются всегда, характеристика — при CI≥50.
5. Лингвистические сигналы (противоречия, хеджи, уверенность) — только эксперименты с правилом решения.
