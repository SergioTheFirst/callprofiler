## 0. Что нового в ревизии 3 (first principles)

Ревизия 3 закрывает три директивы сессии 2026-07-16, не трогая архитектуру Fable:

1. **Модель-решение (§9).** Исследована `empero-ai/Qwythos-9B-Claude-Mythos-5-1M` (fine-tune
   Qwen3.5-9B на трейсах Claude Mythos/Fable). **Вердикт: НЕ переходить** — self-reported
   бенчмарки с неправдоподобной базой (0.232 MMLU у base = ниже случайного угадывания →
   «+34 пункта» не доказательство, а сломанный харнесс либо маркетинг), задокументированная
   деградация при greedy decoding (наш конвейер живёт на temp 0.0-0.3 и строгом JSON),
   ноль заявлений о русском языке (вся промпт-платформа RU), 1M-контекст бесполезен при
   n_ctx=16384/12GB VRAM, «uncensored»-позиционирование нерелевантно. Смена модели =
   HIGH blast radius (инвалидация llm_cache, verbatim-quote контрактов — прецедент смены ASR,
   decisions.md 2026-06-01). Модель ЗАФИКСИРОВАНА инвариантом 27; путь пересмотра — canary-протокол
   §9.3, только по явной команде юзера.
2. **Возраст: одно число (F28, инвариант 26).** Сейчас досье показывает ТРИ возрастных блока
   (маркерный, стилевой, fusion) — юзер фиксирует путаницу двойных значений. Fusion (`fuse-v1`)
   становится ЕДИНСТВЕННЫМ видимым числом на всех поверхностях; маркер/стиль — свёрнутые
   «детали расчёта», не конкурирующие цифры.
3. **Психопортрет уровня «ведущий психоаналитик» (F29-F32, инварианты 28-29).** Глубина
   достигается не спекуляцией, а тем, чем работает реальная клиническая формулировка случая:
   (а) поведение под давлением vs базовая линия (F29); (б) как человек меняет ВЛАДЕЛЬЦА —
   зеркальная динамика (F30); (в) лонгитюд — эволюция сигналов по годам (F31); (г) структурное
   многосекционное досье с критик-пассом и петлёй опровержения владельцем (F32). Каждая строка
   фальсифицируема: теги сигналов + ✓/✗. «Сравнимость с психоаналитиком» операционализирована
   в §10 — иначе это лозунг, а не DoD.

Ось ценности не меняется: покрытие входа × достоверность × доставленность × доверие.

### 3.29 Задача F29 — Стресс-контраст: поведение под давлением *(T2)*

**Научный вектор:** state-vs-trait: устойчивая характеристика — не среднее по всем звонкам, а
ДЕЛЬТА между стрессовым и спокойным состоянием (как человек регулируется под давлением).
Никаких новых извлечений — те же вычислители F15/F16 на двух подмножествах звонков.

**Файлы:** Create: `src/callprofiler/insight/stress_contrast.py`; Modify: `cli` (блок в
`signals-recompute` ПОСЛЕ блоков F15/F16), `dashboard/db_reader.py`, `static/app.js`.
Test: `tests/insight/test_stress_contrast.py`.

1. **Подмножества** (по done-звонкам контакта, role_fragile исключён — инвариант 24):
   - `high = [call_id: analyses.risk_score >= 70]` (Grep колонку risk_score);
   - `base = [call_id: analyses.risk_score < 40]`;
   - гейты: `len(high) >= 3 AND len(base) >= 5`, иначе сигналы НЕ СУЩЕСТВУЮТ (не ноль).
   Константы module-level: `STRESS_RISK_HIGH = 70`, `STRESS_RISK_BASE = 40`,
   `STRESS_MIN_HIGH = 3`, `STRESS_MIN_BASE = 5`.
2. **Расчёт:** вычислители F15 (linguistics) и F16 (dynamics) вызываются read-only с
   `call_ids=high` и `call_ids=base` (параметр из Fable §4.6; штатные таблицы НЕ пишутся —
   тот же контракт, что в F10). Сигналы-дельты (relative, клип [-3..3]):
   ```
   stress:hedge_delta      = (hedge_rate_high − hedge_rate_base) / max(hedge_rate_base, 0.1)
   stress:interrupt_delta  — так же по dyn:interrupts_per_min
   stress:latency_delta    — по dyn:latency_ms
   stress:talk_share_delta — по dyn:talk_share (абсолютная разница, без нормировки)
   stress:profanity_delta  — по ling:profanity_rate (нормировка как hedge)
   ```
   `n` сигнала = `min(len(high), len(base))`; value_json = значения обеих сторон + n обеих
   сторон (шум-доктрина: агрегат всегда с n=).
3. **Интерпретационный словарь** (module-level, для досье и F32; правило — только при
   |delta| выше порога `STRESS_NOTABLE = 0.5`): hedge↑ «под давлением теряет уверенность»,
   hedge↓ «под давлением становится категоричнее», interrupt↑ «давит», latency↑ «замирает»,
   talk_share↑ «забалтывает», profanity↑ «срывается». Ниже порога — «устойчив под давлением»
   (только если ≥3 дельты существуют и все ниже порога).
4. **Досье, секция «Под давлением»** (guarded, внутри психоблока §4.7 Fable — после
   «Динамики»): вердикт-строка из словаря + числа обеих сторон
   («хеджей 12→29/1000 слов, n=5/3»).
5. **Тесты:** подмножества по порогам; гейты (2/3 high → не существует); дельты на
   синтетических значениях (обе полярности, клип); штатные таблицы не записаны (assert
   count до/после); словарь-пороги; value_json несёт n обеих сторон; изоляция.

**DoD:** тесты + полный pytest. `.claude/rules/insight.md` +2 строки. Commit:
`feat(insight): stress-contrast signals — behavior under pressure vs baseline (F29)`.

Наблюдаемый эквивалент: как речь/поведение ВЛАДЕЛЬЦА рядом с этим контактом отклоняется от
его собственной базовой линии по всем контактам. Единственный психослой, легально считающий
по OWNER-речи (явно парный — инвариант 24, ряд «динамика F16, аккомодация B6»).

**Файлы:** Create: `src/callprofiler/insight/mirror.py`; Modify: `insight/linguistics.py` и
`insight/dynamics.py` (+параметр `speaker="OTHER"` — default прежний, поведение всех
существующих вызовов НЕ меняется; Grep все call-sites, убедиться позиционных вызовов нет),
`cli` (блок в signals-recompute), `dashboard/db_reader.py`, `static/app.js`.
Test: `tests/insight/test_mirror.py`.

1. **Базовая линия владельца:** те же метрики (hedge_rate, profanity_rate, politeness_rate,
   intensifiers_rate; dyn: talk_share OWNER-стороны, latency OWNER→OTHER) по OWNER-речи во
   ВСЕХ done-звонках юзера (кэш: считается один раз за прогон signals-recompute, не
   per-contact). Гейт глобальной базы: ≥10000 слов OWNER, иначе весь слой F30 скипается
   со строкой в статистике.
2. **Пер-контакт** (гейт ≥5 звонков И ≥1500 слов OWNER-речи в звонках контакта):
   ```
   mirror:owner_hedge_delta, mirror:owner_profanity_delta,
   mirror:owner_politeness_delta, mirror:owner_energy_delta (intensifiers),
   mirror:owner_talk_share, mirror:owner_latency_delta
   ```
   Нормировка как в F29 (relative к базе, клип [-3..3]); n = слов OWNER у контакта;
   value_json = обе стороны + n.
3. **Интерпретационный словарь** (порог `MIRROR_NOTABLE = 0.4`): politeness↑+hedge↑
   «рядом с ним вы осторожничаете», profanity↑ «расслабляетесь/на своей волне»,
   talk_share низкий «он вас переговаривает», latency↓ «включаетесь мгновенно».
4. **Досье, секция «Вы рядом с ним»** (guarded, после «Взаимности» в порядке §4.7 Fable):
   1-3 строки из словаря + числа. Прямо помечать: «это о ВАШЕЙ реакции, не о нём».
5. **Тесты:** speaker-параметр не меняет дефолтное поведение (регресс: старые вызовы дают
   прежние числа); глобальная база кэшируется (счётчик вызовов); гейты; дельты обеих
   полярностей; секция guarded; изоляция.

**DoD:** тесты + полный pytest. `.claude/rules/insight.md` +2 строки («единственный
OWNER-слой», пороги). Commit: `feat(insight): mirror dynamics — how the contact changes the owner (F30)`.

## 9. Модель-решение: Qwythos-9B-Claude-Mythos-5-1M

### 9.1 Факты (страница HF, зафиксировано 2026-07-16)

- Fine-tune Qwen3.5-9B (та же база и тот же размер, что текущая модель проекта) на 500M+
  токенов трейсов Claude Mythos/Fable + in-house CoT; Apache 2.0; 1M контекст через YaRN;
  reasoning с `<think>`-блоками; «intentionally uncensored»; ~193k загрузок/мес; 98 квантов.
- Заявленные приросты: «+34.3 MMLU (0.575 vs 0.232)», «+30 gsm8k-strict (0.810 vs 0.510)».

### 9.2 Анализ и вердикт: НЕ переходить

1. **Бенчмарки не заслуживают доверия.** База Qwen3.5-9B «0.232 MMLU» — ниже случайного
   угадывания (0.25 на 4-вариантном MMLU). Реальная Qwen3.5-9B так не скорит. Значит харнесс
   сравнения сломан или числа маркетинговые → весь заявленный прирост недоказан. Независимой
   валидации нет.
2. **Прямой конфликт с нашим режимом инференса.** Карточка признаёт: greedy decoding
   «degenerated into repetition loops». Наш конвейер — temp 0.0 (triage), 0.0-0.3 (extract,
   критик-пассы), строгий JSON. Модель с узким сэмплинг-окном — регресс достоверности по
   построению.
3. **Русский язык.** Ни одного заявления о RU; дистилляция на английских трейсах Claude
   типично СДВИГАЕТ базу от мультиязычности. Вся наша промпт-платформа и вся проза — RU.
4. **1M контекст бесполезен:** n_ctx=16384, 12GB VRAM; YaRN-длинный контекст = лишний KV.
   «Uncensored» — нерелевантно (домен благополучный).
5. **Blast radius смены = HIGH** (прецедент смены ASR, decisions.md 2026-06-01): инвалидация
   llm_cache/bio_llm_calls-мемоизации, verbatim-quote контракты (граф/биография/deep-extract)
   зависят от манеры цитирования модели, все PROMPT_VERSION-калибровки под Qwen3.5.
   Плата определена, выгода — недоказана. First principles: не платить установленную цену
   за неустановленную ценность.
6. Примечание: модель дистиллирована из выводов Claude — вопрос совместимости с ToS Anthropic
   оставлен юзеру; на технический вердикт не влияет.

### 9.3 Canary-протокол смены LLM (задача 59a; ТОЛЬКО по явной команде юзера)

Единственный легальный путь пересмотра инварианта 27. Все шаги на боксе, LLM-окно:
